# ===================================================================
- Outil : ChatGPT
- Ce que nous avons demandé (input) : On a chargé et nettoyé notre jeu de données, déterminé notre variable cible (price) et nos caractéristiques, puis séparé nos données en deux ensembles. 80% sont allées pour l'entraînement et 20% pour le test. Je t'envoie le fichier ZIP qui content notre projet. En gros, on a choisi d'utiliser un modèle de régression linéaire pour prédire le prix des maisons selon leurs caractéristiques (bedrooms, bathrooms, sqft_living, sqft_loft, sqft_above, sqft_basement, floors, yr_built, yr_renovated, condition, view, waterfront). Maintenant, on veut entraîner notre modèle de régression linéaire avec scikit-learn. Dans le code que tu vas nous donner, inclue des commentaires dans chaque ligne pour nous expliquer le fonctionnement de celui-ci. 
- Réponse reçue : CHATGPT nous a dit d'utiliser OneHotEncoder() pour transformer nos variables catégorielles (city, view, condition, waterfront) en variables numériques (0 et 1) et ColumnTransformer() pour appliquer cette transformation uniquement aux colonnes concernées. Il nous a aussi dit d'utiliser Pipeline() pour regrouper la préparation des données et l'entraînement du modèle avec LinearRegression(). Il nous a montré le code dans sa globalité avec des # en commentaires pour nous expliquer chacune des lignes de code et comment fonctionne l'entrainement global du modele.
- Vérification faite : On a exécuté le code et vérifié que notre modèle pouvait effectuer des prédictions à partir des caractéristiques des maisons de notre ensemble de test (20% de nos donnees). On a ensuite calculé son RMSE pour évaluer la précision des prédictions et si le tout faisait du sens. Pour etre sure de ce que l'IA avait généré, on s'est renseigné avec la documentation scikit-learn pour déterminer si c'était bel et bien la bonne facon de procéder lorsqu'on a besoin d'entrainer un modèle de régression linéaire.
- Décision — Gardé : On a gardé le code proposé par l'IA, notamment OneHotEncoder(), ColumnTransformer(), Pipeline() et LinearRegression() et on l'a intégré à notre fonction entrainer_modele()

- Ce que nous avons demandé (input) : Voila notre fichier ZIP de notre projet. On a choisi d'utiliser un modèle de régression linéaire pour prédire le prix des maisons selon leurs caractéristiques (bedrooms, bathrooms, sqft_living, sqft_loft, sqft_above, sqft_basement, floors, yr_built, yr_renovated, condition, view, waterfront) et le RMSE comme métrique d'évaluation. Par contre, on doit développer un modèle de référence pour avoir un point de comparaison pour évaluer les performances de notre régression linéaire. Quel modèle de référence serait pertinent? Explique-nous pourquoi ce modèle serait approprié et propose-nous un code permettant de le mettre en place en utilisant les fonctions et les variables que nous avons déjà définies dans notre programme.
- Réponse reçue : ChatGPT nous a proposé un modèle de référence qui consiste à prédire le prix moyen des maisons de l'ensemble d'entraînement, sans prendre en compte leurs caractéristiques. En gros, l'IA nous a dit d'utiliser la fonction mean() de Pandas pour calculer le prix moyen et la fonction np.full() de NumPy pour obtenir la meme prédiction pour chaque maison. 
- Vérification faite : On a exécuté le programme et comparé les résultats des deux modèles. Le modèle de référence a obtenu un RMSE de 334 498$ et celui de la régression linéaire a obtenu un RMSE de 198 776$. Le RMSE de notre régression linéaire était donc plus petite que celui du modèle de référence, la régression linéaire fournissait des résultats plus précis.
- Décision — Gardé : On a gardé l'idée du modèle de référence proposée par l'IA et on a intégré cette proposition dans notre fonction modele_de_reference()
